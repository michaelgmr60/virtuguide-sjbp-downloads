# VirtuGuide SJBP

The Android companion app for exploring St. John the Baptist Parochial School through a virtual campus tour and augmented reality.

## Get the app

Download the APK from [GitHub Releases](https://github.com/michaelgmr60/virtuguide-sjbp-downloads/releases). Android 11 or later and a 64-bit device are required; AR also requires an ARCore-compatible phone.

This is a student thesis alpha. Phone testing is still needed for tracking and sustained performance.

## AR picture markers

The original Elementary, Preschool, SHS and Campus images are in `assets/markers/`. Download the full set from `assets/virtuguide-ar-markers.zip`. Print at 17 × 17 cm, keep the full picture intact, and scan it from the app's AR mode.

## Static website

This repository's root is a plain HTML/CSS/JavaScript website, suitable for GitHub Pages. No build or backend is required. The Unity project source is stored separately and is not included here.
